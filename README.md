# Student Performance Analysis 📊

A Python-based data analysis project that analyzes student performance using **NumPy** and **Pandas**.

## 📌 Project Overview

This project performs data analysis on student performance data stored in a CSV file.

The main purpose of this project is to understand student performance by cleaning, processing, and analyzing the dataset using Python.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas

## 📂 Dataset

The project uses a CSV dataset containing student performance information.

The dataset is included in this repository.

## 🔍 Key Features

- Read student data from a CSV file
- Data cleaning and preprocessing
- Data manipulation using Pandas
- Numerical calculations using NumPy
- Analysis of student performance
- Extraction of useful information from the dataset
